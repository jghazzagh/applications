How to build a widget

  1. Choose a widget type.
  2. Edit the title, message, items, image placeholder, and links.
  3. Choose a preset or customize the colors.
  4. Adjust corners, borders, spacing, and shadow.
  5. Review the 360px preview.
  6. Copy the full code snippet.

How to transfer it to Brightspace

  1. Open the course where the widget will appear.
  2. Open the homepage or widget management area.
  3. Create or edit a custom HTML widget.
  4. Open the HTML/source editor.
  5. Paste the full generated code.
  6. Save the widget, then add it to the course homepage layout.
  7. Preview the course homepage and verify the links, image, spacing, and color contrast.

Replacing placeholders

  • Replace image URLs with files uploaded to Brightspace or another approved source.
  • Replace # links with actual course links.
  • Use descriptive image alternative text.
  • Keep widget text concise because the available width is narrow.

Accessibility reminders

  • Use meaningful link and button text.
  • Do not rely on color alone to communicate meaning.
  • Keep body text at a readable size.
  • Use strong color contrast.
  • Keep headings in a logical order.
Tip: Widgets work best when they provide one focused function. Tiny dashboards become digital junk drawers very quickly.
