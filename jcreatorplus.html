How to use the builder

  1. Select a design element from the dropdown.
  2. Choose the number of repeated items where available.
  3. Edit the generated content fields.
  4. Choose colors, font, size, corners, and shadow.
  5. Review the contrast checks.
  6. Test the live preview.
  7. Copy all generated code.

How to move it into Brightspace

  1. Create or edit a Brightspace content page.
  2. Open the HTML/source editor.
  3. Paste the complete generated snippet.
  4. Save the page.
  5. Close and reopen the page to verify that Brightspace preserved the code.
  6. Test every interactive item with a keyboard and mouse.

Important compatibility note

Some Brightspace environments may remove or restrict JavaScript in content pages. Static items such as callouts and timelines should work broadly. Interactive items such as tabs, flip cards, multiple-choice feedback, and click-to-reveal sections depend on inline JavaScript.

Test interactive elements in your institution’s Brightspace environment before distributing them widely.

Accessibility reminders

  • Use readable text sizes and strong color contrast.
  • Keep headings in a logical order.
  • Use meaningful button and tab labels.
  • Add descriptive alternative text for images.
  • Do not rely on color alone to show correct or incorrect answers.
  • Keep motion subtle and avoid flashing effects.
